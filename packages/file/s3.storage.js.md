# `s3.storage.js` — AWS S3 File Operations

Uploads, reads, and deletes files from an S3 bucket using the `aws-sdk`.

## Configuration

AWS SDK is configured globally with `accessKeyId`, `secretAccessKey`, and `region` from `fileConfig.s3`.

## Exports

### `uploadToS3(buffer, filename, mime)`
Uploads a buffer to S3 with the given key and content type. The object is publicly readable (`public-read` ACL). Returns the full S3 upload response (includes `Location` and `Key`).

```js
const { Location, Key } = await uploadToS3(buffer, 'reports/jan.pdf', 'application/pdf');
```

### `readFromS3(key)`
Fetches an object by key and returns its `Body` as a `Buffer`.

```js
const buf = await readFromS3('reports/jan.pdf');
```

### `deleteFromS3(key)`
Deletes an object from the bucket by key.

```js
await deleteFromS3('reports/jan.pdf');
```

## Dependencies

- `aws-sdk` — AWS S3 client
- `./config.js` — `fileConfig.s3`
